========================Information About Database Password Changes===================== 
The rules for setting a strong database password are listed as follows:
1. The password must contain a minimum of 8 characters and a maximum of 30 characters.
2. The password must contain at least: 
	One lowercase letter [a-z]; 
	One uppercase letter [A-Z]; 
	One numeric character [0-9]; 
	One of the following special characters:
	~ @ # ^ * - _ + [ { } ] : . / ? 
3. The database password cannot be the database user name or the user name in reverse order.
